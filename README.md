# Hey There Sunshine — Boutique Website (Demo)

Demo storefront for **Hey There Sunshine**, a Western-inspired clothing boutique owned by Sunny Looper in downtown Cleburne, Texas.

## What's inside
- `index.html` — a single self-contained page (HTML, CSS, JS — no build step)
- Animated hero (hill-country sunset, windmill, bluebonnets), staggered editorial product grid, category filters
- Quick view with size picker, slide-out shopping bag with free-shipping progress, demo checkout
- Lookbook rail, "Our Story" section with animated Texas map, safe-shopping section, newsletter signup
- Mobile-friendly, respects reduced-motion settings

## Run it
Open `index.html` in a browser. To host free, enable **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / root).

## Before going live
- Replace illustrated products, prices, address, hours, phone and social handle with real ones
- Connect real checkout (Shopify or Stripe) — the demo does not take payments or collect card details
